Personal backup utility / Self-hosted

K0rp-net
Backup.

A private Linux server backup setup designed to store encrypted off-site copies in the operator's own Google Drive account.

Built around rclone for Google Drive transport and restic for encrypted, versioned backups. This is a personal project, not a public storage service.

READ PRIVACY POLICY ↗

What this app is for

01 / PREPARE

Collect designated server data such as project files, archives, and service data for scheduled backups.

02 / ENCRYPT

Encrypt and version backup data locally with restic before any backup content is sent to cloud storage.

03 / STORE & RESTORE

Use Google Drive through rclone to store encrypted backup objects and restore them when needed.

Scope of Google access

The planned integration requests drive.file, allowing access to specific files and folders created by or explicitly made available to the application. It does not request blanket access to unrelated Drive documents. Google authorization is granted by the operator and can be revoked in Google Account settings.

Deployment status

This is an independently operated, personal configuration being set up on the operator's own server. Backup automation, retention and recovery will be tested before the system is relied upon for important data. The public pages document the intended use; they do not expose stored data or administer the server.
