K0rp-net Backup / Data handling

Privacy Policy

Last updated: 24 October 2026

This policy describes the planned and configured data practices of K0rp-net Backup, a personal, self-hosted backup setup using the open-source tools rclone and restic. It is intended for the operator's own Google Drive account, not offered as a public service.

What Google information is accessed

When the operator authorizes Google Drive OAuth, the app requests https://www.googleapis.com/auth/drive.file. With this scope, rclone can access the Drive files and folders it creates or that the user explicitly makes available to it. The integration is not intended to read unrelated Google Drive content, Gmail, Contacts, or Calendar. OAuth may process account information necessary to authorize the connection.

Why the information is used

The Drive access is used only to create, upload, list, verify, download for recovery, and remove backup objects associated with this personal backup setup. No Google user data is used for advertising, profiling, or resale.

Data transfer, storage, and security

The intended workflow encrypts backup content locally with restic before transferring encrypted backup objects through rclone to the operator's Google Drive. Google Drive is the cloud storage provider and receives the encrypted objects. Authentication credentials and refresh tokens are stored on the operator-controlled Linux server in the rclone configuration, subject to local operating-system file permissions. The credentials, keys, and backup encryption password are never published to this website.

Backup job setup and encryption should be verified before any sensitive information is uploaded. No claim is made here that every planned automatic backup is already active.

Retention, deletion, and control

The operator controls when backups run and how many historical versions to retain. Backup objects can be removed from Google Drive by the operator. Authorization can be revoked through Google Account third-party connections; revocation stops further authorized access but does not automatically erase files already stored on Drive.

Third parties and limited use

Encrypted backup objects are transferred to Google Drive as the chosen storage provider. This static website is hosted by GitHub Pages. Neither this site nor the backup workflow is designed to sell Google user data or share it with advertisers. Use of Google API information is intended to comply with the Google API Services User Data Policy, including Limited Use requirements.

This website

The site contains informational pages only. It does not operate an account sign-in, run analytics, or set first-party tracking cookies. GitHub, as hosting provider, may process technical access logs under its own privacy statement.

Changes and contact

This policy will be updated if the actual deployment or its data handling changes. For questions, use the project's GitHub Issues page. Do not post personal data, credentials, tokens, or backup contents in public issues.
